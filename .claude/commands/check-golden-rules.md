
## /check-golden-rules
이 저장소의 골든 룰 6개 위반을 검사한다.

1. 변경된 코드 경로마다 테스트가 함께 변경됐는지 확인 (룰 1).
2. 외부 입력 함수에 검증 로직이 있는지 확인 (룰 2).
3. DB 변경 함수가 트랜잭션 안에 있는지 확인 (룰 3).
4. 코드, 로그, 설정에 비밀처럼 보이는 문자열이 있는지 검사 (룰 4).
5. 이번 PR이 단일 의도인지 확인 (커밋 메시지 분석) (룰 5).
6. 운영 환경 변경이 자동화 게이트를 거치는지 확인 (룰 6).

각 룰별로 통과/위반 결과와, 위반 시 수정 제안을 출력한다.
